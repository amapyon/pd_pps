# M4 試験計画 — スタンドアロンUI（SSD1306 + EC11 + BACK）

更新日：2026-11-02  | 実験：`15_oled_encoder_ui` | 状態：**ソース作成・ホストテスト合格、実機未検証**

## 目的

M3で実機動作を確認したPD/PPS・INA226・OLED・EC11・戻るボタンを維持し、PCシリアルコマンドなしで画面遷移、PDO/APDOの閲覧、PPS要求電圧/要求電流の編集・確認・キャンセルを行えるようにする。初回は**編集プレビューのみ**。機器に実際のPPS要求変更を送るのは、UI挙動確認後の別段階とする。

## 安全設計

- 既存のM3 `14_encoder_ec11`は一切変更せず、新規フォルダーで試す。
- **初回版は`M4_PPS_APPLY_ENABLE=0`。画面で確認を押しても実際のPD要求を送信しない。** シリアル `v` / `i` / `set` コマンドは従来どおり動作し、このUIフラグでは無効化されない。
- 画面上の`REQ ...MA`は**PDへの要求電流**で、INA226の負荷電流`LOAD ...MA`ではない。
- PPSの設定ステップ：画面の電圧は100mV/クリック（20mVの整数倍）、要求電流は50mA/クリック。画面編集可能範囲は現在の選択APDOに基づく。
- 実PPS変更を有効化する前に、現在のSource_CapabilitiesのAPDOを確認し、追加の安全チェックを検証する。電流の要求値は負荷を強制的に制限するハードウェア機構ではない。
- 試験開始時は外部負荷を外す。PD電源OFF、WCH-LinkE停止後に配線を触る。
- I²Cの既存High側入力解放方式とINA226校正係数は変更しない。
- 確認画面でPUSHを1回押しても実PPSが変わらないことを初回版で確認する。
