# 14_encoder_ec11 — M3統合版ファームウェア

更新日：2026-11-02 | 対象：WeActStudio CH32X035 CoreBoard (CH32X035F8U6)

## 目的と状態

M2の実機検証済み`13_oled_ssd1306`をコピーし、EC11の回転(A/B)・軸押し込み・独立した戻るボタンの**入力イベント検出**を追加した独立実験です。

- **完成**：ソースへのM3統合、PCホストテスト10種類（既存9＋M3 1）の合格。
- **未実施**：CH32X035向けクロスビルド、実機Flash、EC11の実物ピン特定、実機回転・押下・戻る入力、PD通信同時運転テスト。
- **M3範囲外**：EC11でPPS電圧・電流を変更すること、メニュー画面。これらはM4`15_oled_encoder_ui`で実装する。
- `11_pps_ina226_monitor`と`13_oled_ssd1306`の既存実験フォルダーは変更しない。

## M2から維持する機能

- PD/PPS交渉、`v`・`i`・`set`・`m`・`s`・`scan`等のシリアルコマンド、切断と再接続。
- CH32X035 PA0のADC測定と校正、INA226の読み出しと換算値。
- INA226/SSD1306のPA2(SCL)/PA3(SDA)ソフトウェアI²C（**High側をGPIO入力に切り替えて解放する方式を含め変更しない**）。
- SSD1306 128×64のPD/PPS設定・BUS電圧・負荷電流・電力表示（元のM2画面を変更しない）。
- 計測電流の絶対精度はM1で未確定。今回校正係数は変更しない。

## M3 GPIO割り当て（実験用・暫定）

| 入力 | MCU信号 | CoreBoard基板表記 | 接続先 | 用途 |
| --- | --- | --- | --- | --- |
| EC11 A相 | PA4 | **A4** | エンコーダーA相端子 | 回転方向／カウント |
| EC11 B相 | PA5 | **A5** | エンコーダーB相端子 | 回転方向／カウント |
| EC11押し込み | PA6 | **A6** | 押し込みスイッチ片端 | 押下イベント |
| 戻るボタン | PA7 | **A7** | 戻るボタン片端 | 押下イベント |
| 共通GND | GND | **GND** | EC11共通端子、押し込み残り、戻るボタン残り | GND共通 |

入力はGPIO内部プルアップ（**非押下HIGH、接点がGNDへ閉じるとLOW**）。EC11/タクトスイッチは無電源の機械式を想定しています。3.3Vや5Vを信号端子に直接配線する必要はありません。PPS VBUSは絶対に接続しないでください。

**重要：EC11の「3本並んだ端子」の中央が必ず共通、などとは現物写真・導通で確認するまで断定しません。** 押し込み2端子と回転3端子を取り違えないでください。モジュール基板型（KY-040等）の場合は回路・VCC仕様確認まで接続禁止です。

`m3_gpio.h`でピンを変更可能ですが、PDのPC14/PC15、SWIOのPC18/PC19、I²CのPA2/PA3、ADCのPA0、LEDのPB12とは競合させないでください。PA4〜PA7の割り当ては**M3ブレッドボード用**であり、最終製品GPIO配置を確定するものではありません。

## 入力処理の設計

- 回転：4状態Gray符号の遷移表を使い、逆方向への接点跳ね返りを相殺。予期しない同時2ビット変化は再同期し、イベントにしない。
- デフォルト1クリック＝**4有効遷移**。EC11の機械仕様によって1クリック＝2遷移などの違いがあり得るため、実機確認してから`m3_input.h`の`M3_QUADRATURE_EDGES_PER_DETENT`を変更する。
- 軸押し込み／戻る：それぞれ25msデバウンス、押下時に1イベント。長押し・連打・二度押し・UI操作への割り当てはM4で検討。
- メインループから2ms間隔を目標にポーリングする（ハード割込みは追加しない）。I²C画面転送やシリアル出力中はタイミングに影響しうるため、M3で実機速度・取りこぼしを評価する。
- **イベントをシリアルモニターに表示するだけ**で、PPS制御・OLED画面・INA226換算には介入しない。

### シリアルで期待するログ例

```text
BOOT: CH32X035 PPS + INA226 + SSD1306 + EC11/BACK (M3)
M3: EC11 CW   pos=1 total=1
M3: EC11 CCW  pos=0 total=1
M3: EC11 PUSH count=1
M3: BACK PUSH count=1
```

CW/CCWの符号はA/Bの実配線と機械的回転に依存します。右回しでCCWと記録された場合、故障とは限りません。配線と相方向の対応を記録してから必要なら定義を反転します。

## Windows 11：配置・ビルド

フォルダー `14_encoder_ec11/` を既存の `13_oled_ssd1306/` と並列に置いてください。`ch32fun/` は既存のものを使用します。

```powershell
cd C:\pj\pd_pps
.\src\pd_pps\dev-workspace\pd-pps.ps1 -Action Build -Project 14_encoder_ec11
```

ファームウェア名：`pps_encoder_ec11.bin`。**最初はBuildのみ**で、Flashは実機EC11の端子配置・接続を確認してから行います。

実機確認後のFlashコマンド：

```powershell
.\src\pd_pps\dev-workspace\pd-pps.ps1 -Action Flash -Project 14_encoder_ec11
```

一般的なGPIO入力の動作を検証するホストテスト（SDK不要）：`cd 14_encoder_ec11 && make test`。これは**CH32X035実機ビルドを代替しません**。
