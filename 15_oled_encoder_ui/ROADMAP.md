## 1. 製品の方向性（決定済み）

| 項目 | 方針 |
| --- | --- |
| 仮称 | **PD/PPS Explorer**（正式名称は未定） |
| 製品の中心価値 | USB PD/PPSの能力を**調べる・設定する・測定する** |
| 販売先 | BOOTH |
| 販売形態① | **組み立て済み完成品**：部品実装・ファームウェア書き込み・出荷検査済み |
| 販売形態② | **ベアPCB**：部品未実装の裸基板。BOM・回路図・組立／書き込み手順を提供する |
| 基板 | 完成品とベアPCBで**同一PCB**を共用する |
| スタンドアロン | ディスプレイと物理操作部で、PCなしでも設定・測定できる |
| PC接続 | PC上のプログラムから設定・測定・記録を行える |
| カスタマイズ | 購入者が独自ファームウェアを書き込める。復旧手段も提供する |
| MCU | CH32X035を基本とする（最終的なリソース適合性は未検証） |
| 電圧・電流計測 | INA226＋R010（0.01Ω） |
| 表示器 | **SSD1306 / 128×64 / I²C** |
| 操作部 | **EC11（押し込み付きロータリーエンコーダー）＋戻るボタン** |

### 重要な設計原則

- PPSの「要求電流」は充電器への要求値であり、**実測電流でも、独立した定電流制限機能でもない**。画面・PC APIで明確に区別する。
- 出力ON/OFFや異常時の保護は、ファームウェアだけに依存しない仕組みを検討する。特に独自ファームウェアの書き込みを許容するため、ハードウェア保護が重要。
- **PD電源用USB-C**と**PC通信・書き込み用USB-C**を分ける案を基本候補とする。ただし、電源分離・逆流防止・MCUピン割り当ては未決定。
- 完成品の全数検査と、ベアPCB購入者が再現できる公開資料を共通の設計データから作成する。
