### 電圧境界の扱い

ユーザー原文は「5V以下」であり、PPS 5.00Vを単独許可する提案は未承認。現行要求はPPS 3.30～5.00VをPC給電必須とする。5.02V以上のPD単独運転は電源の実測条件を満たす場合に許可する設計案。固定5V PDOを通常起動・単独運転・復帰に用いることは推奨案であり、PPS 5.00Vとは区別する。充電器の広告能力・ケーブル・実測電圧・電力制限の範囲内でのみ設定を許可する。

100Wは耐性要求であり100W出力保証ではない。SPR固定20V/5A、PPS上限21Vを設計候補とする。EPRは現時点で対象に含めない案。5Aはケーブル能力確認（E-Marker等）とSourceの広告能力・契約が必要。本体消費を含めた入力電流は契約範囲以内とする。これらの具体上限は要承認。

## 2. 電源アーキテクチャ（推奨候補・未採用）

```text
PD USB-C VBUS ─┬─ [100W負荷経路：計測＋独立保護＋出力SW] ─ 負荷
               └─ [AP63200：4.0V Buck] ─ [OVP＋理想ダイオード] ─┐
PC USB-C VBUS ── [eFuse＋理想ダイオード] ──────────────────────────┤
                                                                 └─ OR ─ [3.3V LDO] ─┐
WCH-LinkE 3.3V ────────────────────────────────────── [排他的切替] ─ MCU/周辺3.3V
```

- ORは低電圧側で実施し、4.0V PD分岐とPC 5Vを自然切替（原則PC優先、電圧公差・経路損失によって変わる）。GND共通、PC/LinkEから負荷へ供給しない。
- AP63200は3.8～32V動作範囲の候補。低電圧PPS中はPD分岐の安定出力に依存しない。3.3V入力での停止・異常動作・逆給電は評価する。PD分岐のEN/UVLO設定も検討。
- TPS25947×2は通常ORとPC保護の候補。過電圧遮断の閾値、出力側定格、応答時間・故障過渡を検証し、低耐圧LDOとPCを保護できるか評価する。最小設定電流0.5AではUSB列挙前100mAを保証できない。PG/FAULTの実際の機能・型番照合も必要。
- AP2112K-3.3はLDO候補。3.3Vの出力精度、入力最大定格、ドロップアウト、熱、リップル・過渡応答を検証。
- WCH-LinkE直接給電は3.3V端子限定を推奨（5V直結不可）。通常3.3Vレギュレータへの逆流を防ぐ排他的ジャンパー等を推奨。全電源を外して切替、負荷を外して書き込む。SWD信号・給電電流・寄生給電・復旧を確認。
- 旧3入力高電圧OR＋昇降圧案（TPS552882、TPS55340等）は現方針では保留。特にTPS25947の出力推奨条件 `VOUT <= min(23V, VIN+20V)` の制約は先行調査で指摘された。入力0Vの分岐に21Vを掛ける旧案を採用しない。仕様値はメーカー最新資料で照合する。

## 3. 運転・安全仕様案（未検証）

| 条件 | 目標動作 |
| --- | --- |
| PDのみ | 固定5V起動案、許容されるPPS高電圧領域で単独運転。PPS 5.00VはPC給電必須として扱う。 |
| PCのみ | CDC・UI動作。PD契約なし、負荷出力OFF。 |
| PD＋有効なPC給電 | PPS 3.3V以上を許可。ローカルUI／CDCに同一ガードを使用。 |
| CDC切断のみ | VBUS・許容電流が維持されれば低電圧継続候補。USBサスペンド条件は別途評価。 |
| PC給電消失・低電圧PPS | ハードウェア負荷遮断。MCUが維持できれば固定5V要求、維持不能なら安全停止。PPS更新停止によるSource側復帰は実機確認し、不能ならPD再接続を案内。 |
| PC給電消失・高電圧PPS | PD単独継続を目標。電源切替波形を確認。 |
| リセット・ブラウンアウト | 出力OFF。古い契約・出力ONを自動復元しない。 |
| SWD書き込み／復旧 | WCH-LinkEのみ給電。PD/PCケーブルと負荷を外す。 |

PC外部給電の有効性はCDCのCOM列挙ではなくOR前VBUS、保護回路状態、電流予算等で判断する。単にVBUSが存在することだけでは安全な給電を保証しない。ADC分圧等の非給電時の逆注入を検証。

負荷出力ENはデフォルトOFF。独立電源監視、低電圧運転インターロック、異常・ブラウンアウト時遮断を検討。GPIOプルダウンのみでMCUハング等の全故障を保護できるとみなさない。大容量ホールドアップコンデンサーは原則採用しない案（自動復帰を保証しない）。主電力経路のeFuse/MOSFET・OCP/SCP/OVP・逆流・温度・放電は未決定。定格100Wの検証は治具を整え段階実施。
