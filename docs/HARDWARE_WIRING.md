## 2. 全体接続図：現在の評価構成

```text
   [PC / Windows 11]                        [別途確立したCoreBoard電源]
        USB-Cデータ                                │
        │                                            ▼
   [外付けUSB-C基板] -- D+/D-、GND --> [WeAct CH32X035 CoreBoard V1.0]
        │     CC1/CC2は基板上のRd            ├─ PC17 / PC16 : USBFS
        └─ PC側VBUS 5V : MCU給電に未接続      ├─ PA2 / PA3   : I²C（ソフト）
                                                  │
                                                  ▼
                                           [CJMCU-226 / INA226]
                                           VCC=3.3V / GND共通
                                               │
  [試験用DC電源 +] -- IN+ -- [R010 0.01Ω] -- IN- -- [外部負荷 +]
  [試験用DC電源 -] ----------------------------- [外部負荷 -]
                                   └─ VBS/VBUS測定点は負荷側IN-（実験11）

  [CoreBoard既存USB-C J1] : 上記PCデータ接続時は未接続
```

これは**電気的な接続関係の説明図**であり、端子の物理配置図／検証済み配線図ではない。外部センサーと追加USB-CはWeAct CoreBoardの標準回路図には掲載されていない。

## 3. CoreBoard V1.0の固定ネット【基板図】

| 機能／信号 | CH32X035F8U6 | 評価基板側の接続・備考 |
|---|---|---|
| USBFS D+（UDP） | **PC17、MCU端子18** | `USB_DP`、既存J1 D+、テストポイント**TP1** |
| USBFS D−（UDM） | **PC16、MCU端子17** | `USB_DN`、既存J1 D−、テストポイント**TP2** |
| USB PD CC1 | **PC14、MCU端子19** | J1 CC1へSB2を介した経路。R4=5.1kΩ→GND |
| USB PD CC2 | **PC15、MCU端子20** | J1 CC2へSB3を介した経路。R5=5.1kΩ→GND |
| I²C SCL（評価配線） | **PA2、MCU端子4** | P1のPA2ヘッダー。**専用I²C端子ではなくGPIOソフトI²C** |
| I²C SDA（評価配線） | **PA3、MCU端子5** | P1のPA3ヘッダー。ソフトI²C |
| VBUS ADC（過去の実験） | **PA0、MCU端子2** | 実験11／PD17の外付け100kΩ/10kΩ分圧。**CoreBoard標準回路図にはこの分圧なし** |
| デバッグDIO | **PC18、MCU端子14** | P3のデバッグインターフェース |
| デバッグDCK | **PC19、MCU端子16** | P3のデバッグインターフェース |
| 表示／操作（別実験） | PA2/PA3、PA4～PA7 | OLEDはI²C共有、EC11等は実験16系。M8ではOLED・操作系を初期化しない |

- 【基板図】J1のUSB D+/D−とTP1/TP2は**同じネット**。USB PD用CCラインとUSBFSデータラインは別の信号である。
- 【基板図】J1のVBUSからVCC/VDD33への基板内電源経路にはダイオード、スイッチ、LDOが含まれる。外部電源を入れる場合は、この実基板の端子と逆流条件を別途確認する。
- 【未確認】追加した配線の半田品質、すべての信号の導通、外付けVBS配線、電源供給端子の最終配線状態は本書から確定できない。

## 4. INA226計測回路（実験11を基準とする）

### 4.1 低電圧側：CH32X035 ↔ CJMCU-226【実験11／M8実機確認】

| CoreBoard | CJMCU-226 / INA226 | 仕様／注意 |
|---|---|---|
| PA2 | **SCL** | GPIOソフトI²C。外部プルアップは**3.3V** |
| PA3 | **SDA** | GPIOソフトI²C。外部プルアップは**3.3V** |
| 3.3V電源 | **VCC** | INA226のデジタル電源。PD VBUSを直接つながない |
| 共通GND | **GND** | MCU、センサー、試験用電源負極の基準を共通化 |
| （未使用） | ALERT / ALE | 実験21では使用しない |

- デバイス7ビットI²Cアドレス：**`0x40`**（A0/A1の実装状態による）。実験11は`0x40..0x4F`を探索可能、M8は`0x40`固定。
- M8はManufacturer ID `0x5449`、Die ID `0x2260`を確認し、CONFIG `0x4527`を設定する。
- CH32X035では通常のオープンドレイン出力が適切に開放されない問題を避け、**High時は入力フローティング、Low時はプッシュプル出力Low**に切り替える。**SCL/SDAは5Vプルアップ禁止**。
- I²Cは信号配線であり、**シャントを通る大電流をSCL/SDA/VCC/GNDの細い信号ヘッダーに流さない**。

### 4.2 高電流側：R010を負荷のプラス側へ直列挿入【実験11】

```text
      試験用電源 V+ ──> [IN+] ── R010（0.010Ω） ── [IN-] ──> 負荷 +
      試験用電源 GND ───────────────────────────────────> 負荷 -
                                         ▲
                                   INA226 VBS/VBUS
                                   （負荷側IN-に接続）
```

| 接点 | 接続相手 | 説明 |
|---|---|---|
| IN+（高電流端子） | 電源側＋ | シャント上流側。電流の正方向はIN+→IN− |
| IN−（高電流端子） | 負荷側＋ | シャント下流側 |
| VBS / VBUS（センサー入力） | 負荷側IN− | 実験11で意図した負荷側バス電圧の測定点。モジュール上で配線済みか**導通確認が必要** |
| 負荷− | 電源GND | 共通帰路 |

- **実験11が計測するのは外部負荷枝の電流**であり、CoreBoard自身の全消費電流とは限らない。INA226の電圧はVBSノード対GND、電流はR010の両端電圧から計算する。
- シャントの**抵抗値0.01Ωと許容電力・配線定格は別問題**。例：5Aではシャント単体の損失は0.25W。基板パターン、コネクタ、配線、ヒューズ、温度上昇も確認する。
- 【未確認】現在のM8実機で外部電源のどの点をIN+、IN−、VBSにつないでいるか。実験11の文書から**M8実機の接続完了を推定しない**。

### 4.3 計測設定・換算（M8実装）

| 項目 | 値・式 |
|---|---|
| INA226 CONFIG | `0x4527`：16回平均、バス／シャント各1.1ms、連続変換 |
| バス電圧 | BUSレジスタの1LSB＝**1.25mV** |
| シャント電圧 | SHUNTレジスタの1LSB＝**2.5µV**（符号あり） |
| 電流（R010） | 2.5µV / 0.010Ω＝**0.25mA/LSB** |
| CDC応答単位 | 電圧`voltage_mV`：整数mV、電流`current_mA`：符号付き整数mA（丸めあり） |
| 計測許容バス電圧 | INA226の仕様上0～36V。**48V EPR不可** |
| 電力 | 実験11は計算表示あり。**M8の`MEASURE`応答には未搭載** |

精度はシャント公差・温度係数・配線電圧降下・ゼロ点・測定器との比較で決まる。`status=ok`は校正済みであることを意味しない。

## 5. PC通信用USB-C追加配線（M5～M8）【試作構成】

| 追加USB-C基板側 | CoreBoard側 | 備考 |
|---|---|---|
| D+ | **TP1 / `USB_DP`（PC17）** | データ線 |
| D− | **TP2 / `USB_DN`（PC16）** | データ線 |
| GND | **GND** | 信号基準 |
| CC1 | 直接接続なし | 追加USB-C基板上の**Rd約5.1kΩ→GND**を使用（既知の試作基板） |
| CC2 | 直接接続なし | 同上 |
| VBUS（PC側5V） | **CoreBoardに接続しない** | 実験18以降の自己給電試作構成。PC側VBUS検出は未実装 |

**配線・運用制限：**

1. **PC用USB-Cと既存J1に同時にUSBケーブルを挿さない。** D+/D−が同じネットにあり、PD電源側のUSBデータ端子との競合は未検証。
2. CoreBoardの電源は**確認済みの独立電源経路**から供給する。PC USBのVBUS 5VをVDD33/3.3Vへ直結しない。VDD33へ外部3.3Vを入れる場合のレギュレータ逆流条件は未確認。
3. D+/D−は短く配線する。試作目安5～10cm程度。電気的・USB規格適合性は未評価。
4. USB-C基板のCC抵抗の有無は**実物で導通・抵抗確認する**。既存Rdがある場合、外付けRdの重ね付けはしない。
5. PC側のUSBケーブル切断をMCUが確実に検知する設計にはなっていない。**製品版ではPC VBUS検出、データ線分離、ESD・逆流防止、給電方式を再設計**する。

USBデータ専用試験中、J1にPD充電器をつながないため、M8の計測対象は**独立した低電圧試験電源・負荷**とする。現試作配線のまま「PC接続しながらJ1からPPS出力を取る」ことは検証済みではない。

## 6. GPIO割当て一覧と共存条件

| GPIO / 信号 | 主な実験用途 | M8での使用 |
|---|---|---|
| PC14/PC15 | J1のPD CC1/CC2 | PDネゴシエーションなし |
| PC16/PC17 | USBFS D−/D+（J1と共有） | USB CDC-ACM |
| PA2/PA3 | INA226、OLED（共有I²C） | INA226ソフトI²C |
| PA0 | PD17/実験11のVBUS ADC（外付け分圧） | 使用しない |
| PA4/PA5/PA6/PA7 | EC11、スイッチ類（実験16系） | 使用しない |
| PC18/PC19 | WCH-LinkEデバッグ | 書き込み／診断用 |

M8は**USB CDC＋INA226の単独実験**。PD、OLED、EC11、ADCとの同時動作はM8では実証していない。

## 7. 通電・検証チェックリスト

- [ ] 実基板のRev、INA226モジュールの表示（R010）、端子シルク、極性を確認
- [ ] CoreBoardの電源経路、3.3V、GND、電源逆流がないことを確認
- [ ] PA2↔SCL、PA3↔SDA、3.3V↔VCC、GND↔GNDを確認
- [ ] I²Cプルアップは3.3V。アイドル時のSCL/SDAがHighであることを確認
- [ ] シャントのIN+／IN−、VBS／IN−導通、大電流の配線定格を確認
- [ ] 初回は**電流制限付き5V程度**の独立電源と小さな抵抗負荷を使用
- [ ] **PD側J1は未接続**（PC用USB-Cを使用する場合）
- [ ] WCH-LinkE接続とMCU電源の相互作用を確認
- [ ] DMMの実測値と`MEASURE`を比較し、測定点・負荷条件を記録
- [ ] USB抜き差し・異常時の復帰・PD同時動作は別試験として扱う
